## 自动化补充

`npm test` 共 71 项通过，`npm run build` 通过。覆盖 22 条地图路线、动态障碍与平滑路径、高度目标、受阻和丢目标时的期望动画、Gizmo 后任务恢复、零速度、30/60/120 FPS 支撑脚滑移、楼梯支撑、全部动作的骨架朝向适配，以及材质修复可逆性。终点附近跟随目标小幅移动的回归也已修复并验证，保留重规划节流和长路线稳定性。

使用实际安装的 Three.js TransformControls 验证了 disable/detach 后清理 dragging、重复结束的幂等性。浏览器通过正常指针操作验证三轴、吸附、撤销和恢复；拖动途中 Escape、系统级 pointercancel、多指触摸未在浏览器端逐项复现。

这些是程序动作与胶囊碰撞演示，尚无针对梯级/地面的手脚接触 IK。服饰、尾巴、体型和台阶交接仍可能有局部穿插；跟拍视线也可能被地图物件遮挡。Android AR 真机、不同设备和其他 VRM 模型仍需另行验收。
